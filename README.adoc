= README

This visual stimulation method was originally developed by by Tom Mayo in 2013,
then edited and Lukas Solanka, Paolo Puggioni, Zahid Pademsay, and Tom
Flossmann.
Currently maintained by Mengzhen Arthur Zhang.

== requirement
. matlab 2022 or later
. gstreamer 1.22.6
. psychtoolbox 3.0.19 (manually installed, not matlab add-on)

== tips
what if psychtoolbox cannot find your gstreamer::
. set gstreamer environment variable inside matlab by
`setenv('GSTREAMER_1_0_ROOT_MSVC_X86_64', 'path\to\gstreamer\')` then
`setenv('PATH', ['path\to\gstreamer\bin;' getenv('PATH')])`

. set environment variable permanently in windows:
    . search and open `edit the system environment variables`
    . click `environment variables`
    . add new under `User variables`
    . then edit Path and add 'path\to\gstreamer\' to the system path too
