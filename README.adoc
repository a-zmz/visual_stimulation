= README

this visual stimulation method was originally developed by zahid pademsay, now
improved and maintained by arthur.

== requirement
. matlab 2022 or later
. gstreamer 1.22.6
. psychtoolbox 3.0.19 (manually installed, not matlab add-on)

== tips
what if psychtoolbox cannot find your gstreamer::
. set gstreamer environment variable inside matlab by
`setenv('GSTREAMER_1_0_ROOT_MSVC_X86_64', 'C:\Program
Files\gstreamer\1.0\msvc_x86_64\')` then `setenv('PATH', ['C:\Program
Files\gstreamer\1.0\msvc_x86_64\bin;' getenv('PATH')])`

. set environment variable permanently in windows:
    . search and open `edit the system environment variables`
    . click `environment variables`
    . add new under `User variables`
    . then edit Path and add 'C:\Program Files\gstreamer\1.0\msvc_x86_64\' to
    the system path too
